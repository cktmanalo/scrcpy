1. Overview

Scrcpy Monitor mirrors one or more Android devices connected over USB or Wi-Fi/TCP, each in its own window, and records their screens. It is built on scrcpy by Genymobile and runs from the Windows notification area (tray) without any console window.

  • One window per device. Every connected device is mirrored automatically, including devices connected after the monitor started. The Connection column shows whether each device uses USB or Wi-Fi.
  • Survives device restarts. When a device restarts or drops off Wi-Fi, its window stays open and mirroring resumes in the same window when the device is back. A device that is turned off, unplugged or closed is removed from the list.
  • Wi-Fi devices. Find devices on the local network with Refresh, connect one by IP address and port, disconnect and reconnect it. Wi-Fi devices are remembered and reconnected automatically.
  • USB or Wi-Fi. Switch a device between USB and Wi-Fi with one click. A device connected over both is mirrored over USB, with Wi-Fi kept on standby.
  • Screen recording. Start and stop recording per device or for all devices from the device window, the control panel or the tray icon. A recording continues across device restarts and is saved as a single MP4.
  • Combined recording. Record several devices at once and get one side-by-side video of all of them, in addition to each device's own recording.
  • Self-updating. The monitor checks GitHub Releases for a newer version and updates itself.

Version number

The version is shown in the control panel title and in About, for example 5.0.1.11: the first three numbers are the scrcpy release the monitor is built on (5.0.1) and the last number is the Scrcpy Monitor build number (11). Include this version when you report a problem. See section 16 for the changes in each version.

2. Requirements

  • Windows 10 or 11 (64-bit).
  • Android device with Developer options > USB debugging enabled. Audio is recorded on Android 11 and later; older devices are recorded without audio.
  • For Wi-Fi/TCP: the PC and the device on the same network.
  • Nothing else to install: scrcpy, adb and ffmpeg are included in the package.

3. Installation

1. Download scrcpy-monitor-portable-<version>.zip from the Releases page (https://github.com/cktmanalo/scrcpy/releases).

2. Right-click the ZIP > Properties > select Unblock (if shown) > OK.

3. Extract the whole ZIP to a folder of your choice, for example C:\Tools\scrcpy-monitor. Do not run it from inside the ZIP.

4. Optional: double-click "Create Desktop Shortcut.vbs" in that folder to add a "scrcpy monitor" shortcut to your desktop.

4. Connecting devices

USB

1. On the device: Settings > About > tap Build number 7 times to enable Developer options.

2. Settings > Developer options > enable USB debugging.

3. Connect the device with a USB cable and accept the "Allow USB debugging" prompt (tick "Always allow from this computer").

Wi-Fi / TCP

ADB over Wi-Fi must be turned on in the device first. The easiest way is from the monitor:

1. Connect the device with USB. It appears in the control panel with Connection "USB".

2. Select it and click Switch to Wi-Fi. The monitor turns on ADB over Wi-Fi (port 5555), connects to the device IP address and moves its window to Wi-Fi.

3. You can then unplug the USB cable.

A device whose ADB over Wi-Fi is already on (for example after "adb tcpip 5555") can be connected without USB:

  • Refresh (control panel) scans the local network on ports 5555 and 5037 and on every port you connected with before, and connects every device it finds. Devices that advertise ADB on the network (mDNS) are also found automatically.
  • Connect Wi-Fi device... (control panel or tray menu) connects one device by IP address and port. Pick a port from the list or type any port (1-65535); you can also type IP:port in the IP address box. A port that connects successfully is remembered: it is added to the list and to Refresh.

Figure 1 - Connect Wi-Fi device

While the device connects, the status bar at the bottom of the control panel shows "Connecting to <IP>:<port>...". If the connection fails, a message explains why. Click Retry to reopen the dialog with the same IP address and port, or Cancel to close it.

MessageWhat to check
No device answered at <IP>:<port>The IP address is wrong, the device is off or on another network, or ADB over Wi-Fi is off. This takes about 20 seconds to report.
The device at <IP> answered, but port <port> is not open for ADBThe device is reachable but the port is wrong, or ADB over Wi-Fi is not turned on for that port.
The address <IP> could not be foundThe IP address or host name is mistyped.
Unlock the device and accept the "Allow debugging" promptTap Allow on the device, then Retry.

ADB over Wi-Fi can also be turned on from PowerShell in the monitor folder (Shift + right-click the folder > Open PowerShell window here), with the device on USB:

.\adb.exe tcpip 5555
.\adb.exe connect <device IP address>:5555

The device is listed as <IP>:<port> with Connection "Wi-Fi". Connected Wi-Fi devices are remembered and reconnected automatically when they drop off the network and when the monitor starts again.

Note: Most devices turn off ADB over Wi-Fi when they reboot. If a Wi-Fi device stays in "Waiting for device" after a reboot, connect it with USB and use Switch to Wi-Fi again.

USB and Wi-Fi at the same time

When a device is connected over both USB and Wi-Fi, it is mirrored over USB only. Its Wi-Fi entry stays in the list, greyed, with Status "Standby (using USB)". If the USB cable is unplugged for more than 30 seconds, the Wi-Fi connection takes over (the USB entry shows "Standby (using Wi-Fi)"), and mirroring returns to USB when the cable is plugged in again. A device that is recording keeps recording on its current connection: a recording over USB waits for the cable to be plugged in again, and a recording over Wi-Fi stays on Wi-Fi when USB is plugged in. If Wi-Fi is lost for 30 seconds while USB is connected, the Wi-Fi recording is saved and a new recording starts over USB (two files).

Switching between USB and Wi-Fi

  • Switch to Wi-Fi (USB device): turns on ADB over Wi-Fi and mirrors the device over Wi-Fi. The device must be on the same network as the PC. If its Wi-Fi entry is on standby, that connection is used.
  • Switch to USB (Wi-Fi device): the USB cable must be plugged in and USB debugging allowed. The device is mirrored over USB and its Wi-Fi connection is ended.
  • While switching, the Status shows "Switching to Wi-Fi..." or "Switching to USB...". When the switch succeeds, the old entry is removed from the list. If it fails, the previous connection is restored and a notification explains why.
  • A recording in progress is stopped and saved before switching (you are asked first).

Disconnect and Reconnect

Disconnect (Wi-Fi devices only) saves any recording, closes the window and ends the ADB Wi-Fi connection; the monitor does not reconnect it automatically until it is started again. Its Status shows "Disconnected". Select it and click Reconnect (or use Connect Wi-Fi device...) to connect it again. USB devices cannot be disconnected by ADB; unplug the cable instead.

5. Starting the monitor

  • Double-click the "scrcpy monitor" desktop shortcut (or scrcpy-monitor.vbs).
  • A window opens for every connected device. The scrcpy monitor control panel appears as soon as the first device screen starts sharing, and the scrcpy monitor icon appears in the tray.
  • Devices connected later get their own window automatically.
  • Starting the monitor again while it is running shows the control panel and reopens any device window you closed; it does not start a second copy.

7. Recording

Start or stop a recording in any of these ways:

  • Device window: click the round button in the top-right corner (red dot = start, white square = stop), or press Alt+E while the window is active.
  • Control panel: select device(s) and click Start recording / Stop recording, or use Recording > Start all / Stop all.
  • Tray icon: right-click the scrcpy monitor icon and choose a device, or Start/Stop recording on all devices.

Figure 3 - Device window while recording (stop button in the top-right corner)

Figure 4 - Recording shown in the control panel

Recordings are saved as:

<Recordings folder>\<Device Name>\Screen_Recording_<Device Name>_<yyyyMMdd_HHmmss>.mp4
  • Each saved recording has a header with the device name and serial above the screen, so you can tell the devices apart. The header is added with ffmpeg in a few seconds after you stop (longer for long recordings); the status bar shows "Adding device name header to <n> recording(s)..." meanwhile. If it cannot be added, the recording is kept without it and the notification says "Recording saved without the device name header".
  • A notification shows the file name when the recording is saved.
  • The recorder takes a few seconds to start, so the first 2-5 seconds after you press start are not in the video. Start recording a moment before the step you want to capture.
  • If the device restarts or disconnects, the part recorded so far is kept, recording resumes automatically when the device is back, and all parts are joined into one MP4 when you stop. The time the device was unavailable is not in the video.
  • Exiting the monitor stops and saves all recordings. If a header is still being added, exit waits up to 2 minutes for it; a recording not finished by then is kept without the header.

Combined recording

Record combined puts several devices side by side in one video, for example to compare the same flow on different terminals.

1. In the control panel, select two or more mirrored devices (Ctrl+click) and click Record combined. Their Recording column shows "REC combined".

2. Stop the devices together (Recording > Stop all, or select them and click Stop recording) or one at a time.

3. Each device recording is saved as usual. When the last device of the group stops, the status bar shows "Combining ..." and the combined video is saved as:

<Recordings folder>\Combined\Screen_Recording_Combined_<yyyyMMdd_HHmmss>.mp4

Figure 5 - Combined recording in progress

Figure 6 - Combined video with a device name above each screen

  • Devices are arranged in a grid (up to three in one row, four as 2x2, and so on), sorted by device name. The video is at most 3840x2160.
  • Every device keeps its own proportions and relative size: all screens are scaled by the same amount, so a smaller screen such as the P630 is not stretched to match the others.
  • A device that is stopped early, or that restarts, shows black in its place for that time.
  • Each screen has a header with its device name and serial, so you can tell the devices apart. The devices are synchronized to about one second. The combined video has no audio.
  • Joining takes from a few seconds to a few minutes depending on length. Exit waits up to 2 minutes for it to finish; if it is still not finished, it is cancelled and a notification says so.
  • If fewer than two devices recorded anything, no combined video is made and a notification says so. The device recordings are kept either way.
  • If a Wi-Fi device falls back to USB while recording (see section 8), both parts are in the combined video.

8. Device restarts

When a device restarts, its window stays open and the Status changes to "Device restarting". When the device is back, mirroring resumes in the same window, and a recording in progress continues in a new part. No action is needed. A device that does not come back within 5 minutes is removed from the list.

A device is removed from the list when:

  • it is turned off (Status "Shutting down", then removed);
  • it is unplugged or drops off Wi-Fi and does not come back within 30 seconds;
  • you close its window or click Stop and close.

A device that is recording is not removed; its Recording column shows "(waiting for device)" and the recording continues if the device comes back. Click Stop recording to save it; the device is then removed. Click Refresh to show closed devices again; devices that come back by themselves reappear automatically.

Note: A restart started with "adb reboot" is not detected as a restart, so the device is removed after 30 seconds and reappears when it is back. Restarting from the device power menu is detected.

If a Wi-Fi device does not come back on Wi-Fi within 30 seconds but is connected with USB, it is mirrored over USB instead; a recording in progress is saved and a new recording starts over USB.

9. Windows, tray and exit

Device windows are arranged on the screen where the control panel is. One device is centered; several devices are placed side by side (or in rows) around the center without overlapping. A window shows the device at full resolution (100%) when it fits; a larger device screen is scaled down to fit and is never cropped. The windows are arranged again whenever a device window opens or closes. Minimized, maximized and fullscreen windows are left as they are, and a restarting device keeps its window in place. After moving windows yourself, click Window > Arrange windows in the panel (or Arrange device windows in the tray menu) to put them back.

  • Closing a device window stops mirroring that device and removes it from the list. Show it again with Refresh in the panel, Refresh devices in the tray menu, or by starting the monitor again.
  • Closing the control panel exits the monitor, the same as Exit: recordings are saved and every device window is closed.
  • The monitor exits by itself when every device window is closed while the control panel is hidden (after a combined recording and the device name headers in progress are saved).
  • Exit (panel or tray menu) saves recordings, closes all windows and quits.

The tray menu (right-click the tray icon) contains:

  • Show control panel
  • One item per device (open its window, start or stop its recording, Stop and close)
  • Start recording on all devices / Stop recording on all devices
  • Connect Wi-Fi device... / Refresh devices
  • Arrange device windows
  • Open recordings folder / Change recordings folder...
  • Open log / Check for updates / Check for updates automatically / About / Exit

10. Recordings folder

The default folder is Videos\scrcpy Recordings in your user profile. Click File > Change recordings folder... in the control panel (or Change recordings folder... in the tray menu) to choose another folder; the choice is remembered, including after updates. The current folder is shown at the bottom of the control panel.

11. Updates

  • The monitor checks for a newer version at startup and when you click Help > Check for updates.
  • To stop the check at startup, turn off Help > Check for updates automatically (also in the tray menu). The choice is remembered; turning it back on checks right away.
  • When a newer version is found, a prompt shows its release notes. Click Yes to install it: the monitor downloads it, stops (saving any recording), updates its folder and restarts. A tray notification then says "Updated to scrcpy monitor <version>", and the title and About show the new version.
  • If you click No, the status bar shows "Update <version> available"; install it later with Install update in About.
  • If recordings are in progress, you are asked to confirm before installing; they are stopped and saved.
  • If the update fails, a message explains why and the current version restarts.
  • If you are on the latest version, a message says "You have the latest version".
  • Your recordings folder and automatic update check settings are kept.

12. About

About (control panel or tray menu) shows the scrcpy monitor version, the scrcpy mirroring engine version, the author, a summary of the application and a link to the project. When a newer version is available, About also shows "Update <version> is available." and an Install update button.

14. Command line (advanced)

Run these from PowerShell in the monitor folder:

powershell -ExecutionPolicy Bypass -File .\scrcpy-monitor.ps1 <options>
OptionDescription
-ListLists the connected devices and exits.
-Serial <s1>,<s2>Mirrors only the given devices.
-RecordStarts recording every device at startup. A device waiting for "Allow USB debugging" starts recording once allowed; a device on standby is recorded on its active connection only.
-RecordDir <folder>Saves recordings to this folder for this run.
-Command StartRecording [-Serial <s>]Starts recording in the running monitor (all devices, or the given ones).
-Command StopRecording [-Serial <s>]Stops recording in the running monitor.
-Command ShowPanelShows the control panel of the running monitor.
-Command ExitExits the running monitor (recordings are saved).
-NoUpdateCheckSkips the update check at startup.
-KeepPartsKeeps the individual recording parts after joining them.
Other scrcpy optionsExtra options (for example --max-size=1024 --stay-awake) are passed to the device windows.
